# StudyVault - Dropdown Flow V3

Plain HTML + CSS + JavaScript demo. No React, npm, Vite, Prisma or external package is required.

## Run
1. Extract the folder.
2. Double-click `index.html`.
3. The project opens in your browser.

## New navigation flow
1. Select University from a dropdown (12 sample universities).
2. Click Next.
3. Select Course / Degree from a dropdown.
4. Click Next.
5. Select Semester from a dropdown.
6. Click Next.
7. Open one of the 5 sample subjects.
8. View Syllabus, Notes and Previous Year Papers.

## Admin demo
Open Admin from the top-right menu.

- Email: admin@studyvault.local
- Password: Admin@123

The admin can edit B.Tech subject names/codes and add/hide/delete sample document paths.

## Important
This is a frontend-only demo. Data is saved in browser localStorage. A real secure admin login and SQL database require a backend.
